### MVP – Shared Party Music Queue

**Goal:** Create a basic working music queue for a party.

- A host can create a music room.
- Guests can add songs to the room's queue.
- The host can see the songs in the playlist.

**Technical Implementation:**
- **Backend:** Node.js, Express, MongoDB (room creation and song queue)
- **Frontend:** TypeScript, React (playlist interface)

**Not included in the MVP:** AI features, automatic queue management, advanced host controls.
